# Sprechstunde

Or's private German course, A1 to B2: a guided daily lesson with spaced repetition, checked speaking and typed answers, placement and level checks.

- Live app: GitHub Pages serves `docs/`.
- Edit content in `src/` (`data.js` is A1, `src/levels/*.js` are A2–B2, rules in `src/levels/BRIEF.md`), check with `node validate.js src/levels/*.js`, then `python3 build.py`.
- Audio: `node collect.js > texts.json`, then `gen_audio.py` with the Coqui Thorsten VITS voice (CC0); packs go to `docs/audio/`.
- Bauen (build-it-yourself sentences, in the style of Language Transfer): `src/build/a1.js` holds one chain of growing English → German prompts per grammar topic (`BUILD[lesson][grammar index]`). The daily lesson runs one chain after the grammar; the last sentences of each chain, plus any missed, return in the warm-up on the spaced-repetition schedule (`S.sents`). Chain sentences are recorded like the rest (`collect.js` picks them up; `gen_audio.py` reuses clips already in the packs, so only new sentences are synthesised).
- The app leads: the home screen shows today's lesson as numbered steps (warm-up, new words, grammar, build sentences, speaking, conversation with Lehrer) and one Start button; Or never picks exercises. When the Lehrer function is set up and Or is signed in, each lesson ends with a short spoken conversation with Lehrer about the day's topic (`convoBrief()` in `src/app.js` sends the lesson brief as the first message). The conversation is German only; the English line of each reply is hidden behind an "English" button. It asks the function for its quick mode (`fast`, `stream`: a smaller prompt, Claude Haiku or Gemini with minimal thinking, and the answer streamed as plain text), so the first sentence shows and is spoken while the rest arrives; each reply shows how many seconds the first words took. The mic keeps listening through pauses and sends after 3.5 s of quiet or on "Senden". Emojis are removed on the server and in the app, and never read aloud. Sentences without a recording (Lehrer's replies, the weekly review) are spoken in the Thorsten voice by a Piper model running on the device in a worker (`TTS_WORKER`, `sayFree()`): onnxruntime-web and the Piper phonemizer from jsDelivr, the `de_DE-thorsten-medium` model from Hugging Face, about 90 MB on first use, kept in the browser cache. The device voice speaks until it is ready or if it fails; Fortschritt → Settings → "Lehrer's voice" switches it off. The Lehrer tab sends Or to today's lesson first.
- Grammar exercises can be answered out loud: the mic button takes the whole sentence (or just the missing words), fills the blanks, picks the option or lays the tiles, and the usual check runs (`teachExSpeak()`). Typing stays for when the mic isn't available.
- Pausing: the running lesson is saved with the progress (`S.run`, see `runSnap()` / `resumeRun()`), so closing the app, the back arrow, or switching devices continues at the same step the same day. A step answered but not yet left continues after it.
- Progress syncs to a private Supabase table when `docs/config.js` has the project URL and anon key.

- Karten (Wortkarten tab, also on the home screen): vocabulary as a card game outside the daily lesson, on the same spaced-repetition cards (`S.cards`), so words learned here come back in the warm-ups. A round is 12 words (due words first, then up to 6 new ones from the current lesson, or from one chosen lesson in "By lesson"). A new word is shown once with its article colour (der blue, die red, das green), then picked from four (one with the wrong article), then typed or said from the English with the article; misses come back a few cards later. Points with a combo multiplier. Artikel-Blitz: 60 seconds of der/die/das, a miss costs 3 seconds, missed articles come up more often (`S.gender`), best score in `S.vocab`. Article rules of thumb (`artRule()`) show only when they fit the word.
- Speech checking weighs words by importance (`align()` in `src/app.js`): names aren't checked (the recogniser can't know them), German place names count half, articles, negation, numbers and endings count fully and a wrong one never passes, short words count less, and fillers (äh, ähm) are ignored. A sentence passes at 90%; near misses on ordinary words are marked but can still pass.
- Motivation: the daily goal is one lesson (or 10 minutes of practice, counted while a practice screen is in use); each day the goal is met adds to the streak (`goalMet()`, `streak()`). Home shows the streak, the last 7 days and "Your way to B2" (a bar per level); passing a level check is a milestone.
- Daily reminder: a push notification from Lehrer at a time Or picks, sent only when today's lesson isn't done. On the iPhone it works in the app opened from the Home Screen (iOS 16.4+). Server side: run `supabase/reminders.sql` once in the SQL editor (tables plus a 15-minute cron job), then create the function `erinnerung` from `supabase/functions/erinnerung/index.ts` (no secrets; it makes its own push keys). The app saves `S.where` (today's lesson) with the progress so the note can say where Or left off. `docs/sw.js` only shows the notification.
- Weekly check-in: once a week (7 days after the last one, or after the first week of practice) the daily lesson starts with "Wochenrückblick": the week's numbers, then Lehrer's review (what got better, what to practise) and one goal, which shows on the home screen and goes into the learner profile (`S.weekly`, history in `S.weeks`). Without Lehrer the review is written from the numbers. It runs on the existing `lehrer` function, so no server change.

## Lehrer (AI teacher)

The Lehrer tab is a full-screen chat (a slim bar with the model, past chats and New on top, the input at the bottom, sized by `fitChat()`) with a German teacher that gets a short learner profile with every message: level, current lesson and grammar, words Or keeps missing, wrong articles, and recent word and exercise mistakes (`learnerProfile()` in `src/app.js`).

- Without setup it offers "Open in Claude" / "Open in ChatGPT", which start a chat on Or's own subscription with the teacher instructions and profile filled in.
- The in-app chat calls the Supabase function in `supabase/functions/lehrer/`, which holds the model API keys and only answers Or's account. Each key set under Edge Functions → Secrets adds a model to the picker in the Lehrer tab: `GEMINI_API_KEY` (Gemini 3.8 Flash, free tier), `MOONSHOT_API_KEY` (Kimi K3), `ANTHROPIC_API_KEY` (Claude Sonnet 5.5). Deploy with `supabase functions deploy lehrer`, or paste `index.ts` into a new function named `lehrer` in the dashboard.
- Memory is kept in the app, not by the model provider: the recent chat (`S.chat`) and the teacher's notes (`S.tnotes`) sync with the rest of the progress and go with every message, whichever model answers. The teacher adds or removes notes through a hidden `<memory>` block in its reply; Or can see and delete them under "What I remember about you".

All lesson content was written for this app.
